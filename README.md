v# 🍕 PizzaBot - AI Chatbot

A retrieval-based AI chatbot for pizza delivery, built with Node.js and Express.

## Features
- 💬 Instant responses to customer queries
-  Predefined patterns for menu, orders, hours, and location
- 🎨 Beautiful, colorful UI with floating chat widget
- 📱 Responsive design for mobile and desktop

## Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd pizza-bot

## 🛠️ How to Run in VS Code

Follow these steps to run the PizzaBot locally using Visual Studio Code:

1. **Open the Project:**
   - Open VS Code.
   - Go to **File > Open Folder** and select the `pizza-bot` folder.

2. **Open the Terminal:**
   - Press `` Ctrl + ` `` (backtick) on your keyboard, or go to the top menu and select **Terminal > New Terminal**.

3. **Install Dependencies:**
   - In the terminal, make sure you are in the root `pizza-bot` directory.
   - Run the following command to install Express and CORS:
     ```bash
     npm install
     ```

4. **Start the Server:**
   - Once the installation is complete, run the server:
     ```bash
     node server.js
     ```
   - You should see a success message: `🍕 PizzaBot server is running on http://localhost:3000`

5. **View the Website:**
   - Open your web browser (Chrome, Firefox, Edge, etc.).
   - Go to: **http://localhost:3000**
   - Click the floating  button in the bottom right corner to start chatting!

6. **Stop the Server:**
   - To stop the bot, go back to the VS Code terminal and press `Ctrl + C`.
